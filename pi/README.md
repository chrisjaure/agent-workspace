# Pi Agent Configuration

This directory is the Pi agent directory when launched through `../agent-workspace`.

- Global instructions: `AGENTS.md`
- Pi settings and agent extensions: `settings.json` and `extensions/`.
- Zellij setup and the `Agent` layout: `../zellij/`
- Launch the workspace with `../agent-workspace`.

Local credentials, trust state, sessions, and generated package data are excluded from version control. The permission system's global policy is in [`extensions/pi-permission-system/config.json`](extensions/pi-permission-system/config.json); this workspace's project-specific policy is in [`../.pi/extensions/pi-permission-system/config.json`](../.pi/extensions/pi-permission-system/config.json). See the [Pi permissions guide](../docs/guides/pi-permissions.md) for scope, reload, and disable options.

## Extensions

These packages are declared in `settings.json`:

- [@gotgenes/pi-permission-system](https://pi.dev/packages/@gotgenes/pi-permission-system): Pi doesn't ship with a permission system by default. Still evaluating.
- [pi-context-view](https://pi.dev/packages/pi-context-view): Provides excellent visibility into the context used by the agent. Necessary for context engineering.
- [pi-zentui](https://pi.dev/packages/pi-zentui): Adds more styling knobs to customize the looks without building my own extension. Not required.
- [pi-observational-memory](https://pi.dev/packages/pi-observational-memory): Enables long-running tasks. Doesn't seem to be actively maintained; open to other options.
- [pi-advisor-flow](https://pi.dev/packages/pi-advisor-flow): Enables the use of a cheaper model as the driver. The agent or I can reach for a stronger model to review a plan or verify an outcome. Still evaluating.

### Custom Extensions

- [`/edit`](extensions/edit.ts): Opens the last file mentioned by the agent in the editor in a Zellij floating pane. I often want to tweak or review documents generated by my agent, and this shortcut reduces a lot of friction.
